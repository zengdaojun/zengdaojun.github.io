def solution(expression):
    ops = [] # 存储运算符
    nums = [] # 存储数字
    for ch in expression:
        if '0' <= ch <= '9':
            nums.append(int(ch))
        elif ch =='(':
            ops.append(ch)
        elif ch == ')':
            top = ops.pop()
            while top !='(': # 匹配最近的一个(
                n2 = nums.pop()
                n1 = nums.pop()
                r = calc(top, n1, n2)
                nums.push(r)

def calc(op, n1, n2):
    match op:
        case '+': return n1 + n2
        case '-': return n1 - n2
        case '*': return n1 * n2
        case '/': return n1 // n2
    raise ValueError(f'invalid op: {op}')

注意到AI给出的提示代码不是样板代码，而是根据我们自己编写的代码来改进的，它提示了一个编码错误（应该是append()而不是push()），补充了一行漏掉的关键代码（ops.append(ch)），将solution()函数写完了，并定义了一个has_higher_priority()函数来比较运算符优先级。

不过这个has_higher_priority()函数扩展性不是很好，我们把它改进一下：

OP_PRIORITY = { '*': 2, '/': 2, '+': 1, '-': 1, '(': 0 }

def has_higher_priority(op1, op2):
    return OP_PRIORITY[op1] >= OP_PRIORITY[op2]

这样我们就借助AI完成了所有代码的编写。在线运行一下，可以得到正确的结果，如果结果有误，还可以在线调试，找到错误并修正。
